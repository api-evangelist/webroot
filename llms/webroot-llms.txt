# Webroot

> Webroot (now part of OpenText Cybersecurity) provides endpoint protection,
> DNS protection, security awareness training, and BrightCloud threat
> intelligence. Its developer-facing surface is the Webroot Unity API — a
> REST/JSON platform (OAuth2) for managing product licenses, orders, sites, and
> endpoint status across the Webroot Global Site Manager (GSM) console.

## APIs

- [Webroot Unity API](https://unityapi.webrootcloudav.com/docs): REST/JSON management API. Authenticate once via OAuth2 (`/auth/token`), then call `/service/api` resources with a bearer token. Covers license/order provisioning, order queries, and endpoint status.
